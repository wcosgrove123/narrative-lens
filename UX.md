1. User Stories
This section breaks down the app's features into goal-oriented actions from the perspective of our user, Alex.

1.1. Library & Story Management
As a photographer, I want to create a new, named story so that I can group photos from a single event or theme together.

As a creator, I want to see all of my stories in a visual library so that I can quickly find and open the project I want to work on.

As a user, I want to be able to delete a story so that I can remove old or unwanted projects.

As a curator, I want to choose a specific photo as the cover image for my story so that my library is organized and visually appealing.

1.2. Story Editing & Creation
As a creator, I want to easily import multiple photos from my computer at once so that I can get all my raw materials into the app quickly.

As a storyteller, I want to drag and drop my photos into a specific sequence so that I can control the narrative flow and pacing of my story.

As an artist, I want to apply simple filters to my photos with one click so that I can quickly establish a consistent mood and tone.

As an editor, I want to adjust basic sliders like brightness and contrast so that I can make minor corrections to individual photos.

As a narrator, I want to add a text caption to each photo so that I can provide context, commentary, or emotional insight.

As an author, I want to write a title and introduction for my story so that I can set the stage for the viewer.

1.3. Portfolio & Sharing
As a professional, I want to toggle a story between "private" and "public" with a simple switch so that I have full control over what I showcase.

As a job-seeker, I want a single, clean, shareable URL for my portfolio so that I can easily link to my work on my resume or social media.

As a creator, I want to add a short bio and my contact information to my portfolio page so that potential clients or collaborators can learn about me and get in touch.

As a visitor (to the portfolio), I want to view the published stories in a clean, scrollable presentation so that I can experience the narrative without distractions.

2. User Flow Diagrams
These diagrams map out the primary paths Alex will take through the application.

2.1. Flow 1: Creating and Editing a New Story
This flow covers the core creation process from start to finish.

[Start]
Open App -> View Story Library Screen -> Click "Create New Story" Button -> Enter Story Title in Pop-up -> Click "Create" -> [Enter Story Editor Screen] -> Click "Import Photos" -> Select Photos from File Explorer -> Photos Appear in Photo Bin -> Drag & Drop Photos onto Canvas -> Reorder Photos on Canvas -> Select a Photo -> Adjust Sliders/Apply Filter -> Write Caption for Photo -> (Repeat for other photos) -> Edit Main Story Title/Intro -> [Story is auto-saved] -> Click "Back to Library" -> View Story Library Screen (with new story visible)
[End]

2.2. Flow 2: Publishing a Story to the Portfolio
This flow details the simple process of making a finished story public.

[Start]
Open App -> View Story Library Screen -> Click on an Existing Story -> [Enter Story Editor Screen] -> Review the Story -> Click the "Publish to Portfolio" Switch (from Off to On) -> See Confirmation Message ("Story is now public!") -> (Optional) Click "View Public Portfolio" Link -> [Browser opens new tab with Portfolio URL] -> See the newly published story in the portfolio grid
[End]
