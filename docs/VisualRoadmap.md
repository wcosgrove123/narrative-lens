1. Vision & Strategy
This roadmap outlines the development plan for the "Visual Narrative" app. The strategy is to follow an iterative development process, beginning with a Minimum Viable Product (MVP) to establish the core functionality. Subsequent versions will build upon this foundation by adding layers of creative tooling and public-facing features, allowing for user feedback to guide later stages.

Version 1.0: The MVP — The Core Creation Tool
Theme: "Get it working, not perfect."
Timeline: Q4 2025 (October - December)
Goal: To deliver a functional, standalone application that allows a user to create, organize, and save a complete photo story. This version focuses exclusively on the core workflow. Success is when your brother can build his first complete story, even without advanced editing or sharing.

Key Features & User Stories:
Story Library & Management:

Implement the main library/dashboard screen.

Functionality to create a new, named story.

Functionality to delete an existing story.

Ability to set a cover image for each story.

User Story: "As a photographer, I want to create a new 'story' so that I can group photos from a single game together."

Basic Story Editor:

Implement the two-column editor layout.

Photo Import: Allow users to select multiple photos from their local computer and add them to the "Photo Bin."

Sequencing Canvas: Enable drag-and-drop functionality to arrange photos from the bin onto the main canvas and reorder them.

User Story: "As a storyteller, I want to drag and drop my photos in a sequence so that I can control the narrative flow."

Persistence:

Ensure that all created stories and their photo sequences are saved locally so the user's work is not lost when the app is closed.

What's NOT in this version: Photo editing, captioning, publishing, public portfolio.

Version 1.1: The Storytelling Update
Theme: "Adding the soul."
Timeline: Q1 2026 (January - March)
Goal: To enhance the core product with tools that allow for creative expression and narrative context. This version moves beyond simple sequencing and allows the user to shape the mood and meaning of their story.

Key Features & User Stories:
Tone Editor Implementation:

Add the "Tone Editor" panel to the UI.

Implement basic image adjustment sliders (Brightness, Contrast, Saturation).

Create and implement a set of 5-6 predefined, one-click filters (e.g., "Gritty B&W," "Cinematic").

User Story: "As an artist, I want to apply simple filters to my photos with one click so that I can quickly establish a consistent mood."

Captioning Functionality:

Add a text input field beneath each photo in the Story Editor's canvas.

Add a main text block at the top of the story for a title and introduction.

Ensure captions are saved with the story.

User Story: "As a narrator, I want to add a text caption to each photo so that I can provide context or emotional insight."

What's NOT in this version: Publishing, public portfolio.

Version 1.2: The Showcase Update
Theme: "Going public."
Timeline: Q2 2026 (April - June)
Goal: To bridge the gap between the private creation tool and a professional, public-facing platform. Success is when your brother can share a single URL that showcases his polished work to the world.

Key Features & User Stories:
Publishing Workflow:

Implement the "Publish to Portfolio" toggle switch in the Story Editor.

Create the backend logic to differentiate between public and private stories.

User Story: "As a professional, I want to toggle a story between 'private' and 'public' so that I have full control over what I showcase."

Public Portfolio Page:

Build the public-facing web page (the portfolio).

The page must dynamically display a grid of all stories marked as "public."

Include an editable section for a user bio and contact links.

User Story: "As a job-seeker, I want a single, clean, shareable URL for my portfolio."

Public Story Viewer:

Create the presentation view for a single story, linked from the portfolio. This page should display the sequenced photos and their captions in a clean, scrollable format.

Future Versions (Post-Launch Ideas)
Theme: "Refine and expand."
Timeline: H2 2026 and beyond
Goal: To act on user feedback and explore new avenues for the product. These features are currently out of scope but represent potential growth areas.

Layout Templates: Allow users to choose different layouts for their stories (e.g., side-by-side images, full-bleed images with text overlay).

Cloud Sync & User Accounts: Move beyond a local-only app to a cloud-based service, allowing access from multiple devices.

Enhanced Sharing: Export a story as a video slideshow (MP4) or a PDF document.

Video Support: Allow short video clips to be included in the narrative sequence.

Mobile Companion App: A dedicated mobile app for viewing stories or making quick edits on the go.
